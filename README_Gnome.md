# GSoC 2025 - GNOME Terminal Modernization

This repository contains my work and plans for modernizing GNOME Terminal by migrating to GTK4 and updating integration with the latest VTE.

## Objective
- Migrate GNOME Terminal from GTK3 to GTK4
- Ensure compatibility with latest VTE API
- Preserve all existing features and improve UI consistency

## Proposal
Full proposal available here: [Priyanshu's GSoC 2025 Proposal - GNOME Terminal](https://github.com/PriyanshuValechha)

## Deliverables
- GTK4 UI migration
- Refactored VTE integration
- Feature parity testing
- Documentation and build steps

## Status
Work in progress. This repo will be updated with research, code snippets, and weekly logs.
